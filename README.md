# Surveys for the GEMs Project

This repository contains the survey source code for the [Genomics Education Modules (GEMs) Project](https://genomicseducation.org/). GEMs is funded by the National Human Genome Research Institute under award 1R25HG013489.

## Student Pre Survey

This directory contains the survey targeted at students pre-module completion. It can serve as a baseline.

## Student Post Survey

This directory contains the survey targeted at students post-module completion. It serves to measure improvement and collect general feedback.
